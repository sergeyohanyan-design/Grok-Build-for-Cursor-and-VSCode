# Grok Build for Cursor and VSCode

Sidebar for the Grok Build CLI over the Agent Client Protocol. Built first for Cursor; also runs in VS Code.

**Not affiliated with, endorsed by, or maintained by xAI.**

Based on [SahilRakhaiya05/Grok-Build-GUI](https://github.com/SahilRakhaiya05/Grok-Build-GUI) (MIT).

## Requirements

- Cursor or VS Code 1.94+
- Grok CLI installed and signed in

## Features

- Agent chat sidebar with plan, agent, and YOLO modes
- File context, session history, and edit approvals
- Model picker and reasoning effort controls
- Windows system voice, chat copy/paste, screenshot vision, and file attach

## Install CLI

Download the Grok CLI from the official xAI site, then run `grok /login`.

## Settings

Configure `grok.cliPath` if the CLI is not on your PATH.
